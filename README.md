Проєкт «Менеджер задач»
Цей проєкт зроблений для зберігання завдань та їхнього виконання. Зі зберіганням даних на дисці для зручного користування.

В цьому проєкті є пароль для захисту, автозбереження даних в JSON. Також можна добавляти, видаляти, позначати виконаними  завдання.

В цьому проєкті було поєданно Python 3, модулі json, random, система Git.

Інструкція із запуску
1. Завантажити або клонувати репозиторій на комп'ютер.
2. Відкрити папку проєкту у терміналі.
3. Переконатися, що на комп'ютері встановлено Python 3.
4.Запустити програму командою: python main.py
Примітка: якщо головний файл програми має іншу назву, замість main.py потрібно вказати її.
5.Створити майстер-пароль (не менше 8 символів).
6.Ввести пароль для входу та користуватися меню програми.
